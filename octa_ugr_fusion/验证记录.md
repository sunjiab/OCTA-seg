# UGR-Fusion 实现验证

日期：2026-09-24。以下为工程验证，不是正式研究结果。

## 自动测试

运行 `conda run -n octa pytest -q octa_ugr_fusion/tests`，结果 **6 passed**。

检查了：初始输出与同一模型的 OCTA anchor 等价；偶数和奇数图像尺寸；零初始化输出层更新后 OCT 输入可收到梯度；logit 修正幅度不超过设计上限；容量控制不依赖 OCT；真阳性保留项的方向与背景排除；空标签与血管标签下 soft-clDice 梯度有限；打乱映射不会保留病例自身的 OCT。

## 真实数据训练

在已有 octa 环境、CUDA 下运行：

```bash
python octa_ugr_fusion/train.py --epochs 1 --workers 0 --skip-test \
  --output-dir octa_ugr_fusion/runs/smoke_capillary
python octa_ugr_fusion/train.py --target GT_Vein --cldice-weight 0.1 \
  --epochs 1 --workers 0 --skip-test \
  --output-dir octa_ugr_fusion/runs/smoke_vein_topology
```

两组各完成140例训练、10例验证，checkpoint 保存/重载、AMP、损失和八列可视化均成功。毛细血管验证 Dice 约0.7739；静脉加clDice的验证 Dice约0.3152。只有一轮，不能据此声称优于旧方法、解决静脉问题或评估收敛性能。

新模型参数量 **7,919,371**，原单模态 U-Net 为7,762,465，增加156,906，约2.02%。计算量和耗时不能由参数量增长直接推断。

## 推理消融

`evaluate.py` 已在 smoke 毛细血管模型的验证集执行正常、置零、三次打乱 OCT，生成指标 JSON、逐病例 CSV、门控/修正图。评估采用与训练配置一致的AMP设置；可视化为float32推理，阈值附近少量像素可能有数值差异。

所有 smoke 均指定 `--skip-test`，未运行正式测试集指标。正式100轮实验、多seed比较和模型有效性验证待完成。该实现保存训练状态，但尚无resume入口；后续运行使用README中的命令及新输出目录。

## GT_LargeVessel 扩展

数据集的 `GT_LargeVessel` 目录共有500张 BMP，3 mm 病例10301–10500均存在。UGR 与原 early-fusion 入口均已将该标签加入参数选择。

运行：

```bash
python octa_ugr_fusion/train.py --target GT_LargeVessel \
  --epochs 1 --workers 0 --skip-test \
  --output-dir octa_ugr_fusion/runs/smoke_large_vessel
```

一轮真实训练和验证完成，正常保存 config、history、best/last checkpoint、验证指标和八列预测图。该轮验证 Dice 约0.5500，仅证明流程可运行。新旧融合测试合计 `9 passed`。正式大血管结论需完成同入口 OCTA-only、early fusion、UGR 三组完整训练后再比较。
